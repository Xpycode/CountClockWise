# Clocks and Windows

Use **File → New Clock** to open an independent clock. Each window remembers its display settings, label, time zone and position.

Open **Count Clock Wise → Settings** with Command-Comma. Settings apply to the selected clock except where an option says it applies to the whole app.

In **Time Zone**, search cities, countries, regions, abbreviations or UTC offsets. Select a result to use it immediately. Choose **Use System Time Zone** to follow the Mac. Favourite zones are shared between windows.

Use **Controls** or right-click the clock for display options. The optional status bar shows the date, time zone, custom label and frame rate.

Closing a clock removes that window from the set restored next time. Closing the last window leaves Count Clock Wise available through its menu-bar icon. Choose **Quit Count Clock Wise** with Command-Q to exit.

## Launch at Login

Keep the app in Applications. In **Settings → Window**, enable **Launch at login**. macOS may ask you to approve the login item in System Settings. The option can only be fully tested by logging out and back in.
