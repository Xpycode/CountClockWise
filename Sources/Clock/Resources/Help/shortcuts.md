# Keyboard Shortcuts

| Action | Shortcut |
| --- | --- |
| New clock | Command-N |
| Settings | Command-Comma |
| Count Clock Wise Help | Command-Shift-/ (Command-?) |
| Compact / full view | Tab |
| Start or pause timer | Space |
| Close window | Command-W |
| Minimize | Command-M |
| Full screen | Control-Command-F |
| Quit | Command-Q |

The default global shortcut to show or hide all clocks is **Control-Option-Command-C**. Customize or disable it in **Settings → Window**. The View menu displays the currently configured shortcut. If another app already uses your choice, select a different combination.

The menu-bar icon also provides Show / Hide All Clocks, New Clock, Settings and Quit.
