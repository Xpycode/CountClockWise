# Countdown and Stopwatch

Choose **Clock**, **Countdown** or **Stopwatch** in the toolbar or Controls menu.

Use **Start**, **Pause** and **Reset** below the time. You can also click the time or press Space to start or pause the active timer. Switching modes pauses the timer you leave; each timer mode retains its own elapsed time.

For a countdown, choose **Set Duration** and enter hours, minutes and seconds. The total must be between one second and seven days. Minutes and seconds must each be between 0 and 59. Invalid input disables **Set Duration**.

At completion, the clock turns red, beeps and requests attention. A system notification also appears when macOS allows it. Approve the notification request when first starting a countdown; permissions can be changed later in System Settings → Notifications → Count Clock Wise.

Running timers retain their start time across app relaunches. Count Clock Wise must be running to deliver completion feedback. If it is closed or the Mac is asleep at the deadline, feedback is delayed until Count Clock Wise next runs. Changing the Mac's time can affect elapsed time.
