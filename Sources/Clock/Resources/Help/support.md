# Updates, Privacy and Support

Use **Count Clock Wise → Check for Updates** to check for a newer release. Automatic checks can be configured in Settings. Local development builds may not yet have a published update channel; the app will explain when updates are unavailable.

Choose **Help → Send Feedback** to report a bug or suggest an improvement. Describe what you did, what you expected and what happened. Feedback is sent only when you explicitly submit it. Optional contact information and diagnostic attachments are your choice.

**Help → Leave a Tip** opens the developer's optional tip page in your browser. It does not change any app features or initiate a payment automatically.

## Privacy and Diagnostics

Clocks and city search work offline. Count Clock Wise preferences stay on this Mac. Network connections are used for update checks and feedback when those features are used.

Diagnostic logs contain bounded operational events and error codes, not clock labels, selected cities or timer values. **Help → Show Diagnostic Log** reveals the log so you can review it before sharing. Logs are not uploaded automatically.

If notification delivery fails, check System Settings → Notifications → Count Clock Wise. Focus modes and notification settings may suppress banners. Launch at Login must be tested through an actual login with the installed app enabled.
